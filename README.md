**Finance Analysis Dashboard | Power BI**
**Project Overview**
The Finance Analysis Dashboard is an interactive data analytics project developed using Microsoft Power BI.
This project focuses on analyzing financial transactions, customer segments, tax distribution, transaction performance, and geographical financial trends.
The dashboard transforms financial data into meaningful business insights through interactive visualizations, KPI indicators, and dynamic filters.
**Dashboard Preview**

**1. Overview Analysis**
This dashboard provides a comprehensive overview of financial performance through key performance indicators and interactive visualizations.
**Key Highlights**
: Total Amount and Transaction Analysis
: Average Transaction Value
: Total Fees and Total Tax
: Monthly Tax Trend Analysis
: Tax Distribution by Transaction Status
: Customer Segment Analysis
: State-wise Financial Analysis
: Gender-wise Transaction Analysis

**2. Transaction Analysis**
This dashboard provides detailed transaction-level information to analyze customer activities and financial records.
**Key Highlights**
: Transaction ID and Transaction Date
: Customer Name and Transaction Type
: Gender and Customer Segment
: State-wise Transaction Details
: Total Transaction Amount
: Total Fees and Total Tax
: Interactive Year and Category Filters

**How to Use**
: Download or clone this repository.
: Open the Finance_Analysis_Dashboard.pbix file using Microsoft Power BI Desktop.
: If required, update the dataset source path.
: Refresh the data in Power BI.
: Explore the interactive dashboard using the available filters and visualizations.

**Project Objective**
The main objective of this project is to analyze financial transactions and convert raw financial data into meaningful business insights.
It helps understand financial performance, customer behavior, transaction patterns, and tax distribution through interactive Power BI dashboards.
